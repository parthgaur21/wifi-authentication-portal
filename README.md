# WiFi Authentication Portal

A web-based WiFi authentication system that allows visitors to register through a QR code and receive room-specific WiFi credentials.

## Features

- Visitor Registration
- QR Code Based Access
- Room Verification
- Admin Dashboard
- Supabase Integration

## Tech Stack

- React
- TypeScript
- Vite
- Supabase
- Tailwind CSS

## Installation

```bash
npm install
npm run dev
